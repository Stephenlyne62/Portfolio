Featured Case Study

RestBoo

View GitHub View README

A restaurant booking and management platform built around four distinct user roles, combining customer-facing booking experiences with restaurant administration, messaging, analytics, and staff workflows.

2026 Team Project Front-End Ownership
Role Sole Front-End Developer
Core Stack Pug · JavaScript · Mustache.js
Product 4 Role-Based Experiences
Delivery Multi-Developer Team

The Product

One platform.
Four user experiences.

Restaurant booking products need to serve several audiences at once. Customers need simple restaurant discovery and reservation management, while restaurant teams need operational tools for bookings, menus, staff, availability, media, and analytics.

RestBoo brought those workflows into one application while preserving a clear experience for each type of user.

My Role

Complete front-end ownership.

As the sole front-end developer, I delivered the complete user-facing implementation within the project team, translating backend functionality into responsive, role-based user journeys.

  • Restaurant discovery and booking flows
  • Booking management, messaging, and profiles
  • Restaurant and staff administration
  • Image upload and gallery management
  • Analytics dashboards and data visualisation
  • Authentication, validation, and API states

Challenges

Key engineering challenges

The complexity came from supporting multiple audiences and workflows while keeping the product consistent.

01

Four user roles

Different navigation, permissions, workflows, and interface states without making the application feel fragmented.

02

API-driven interfaces

Loading, validation, successful responses, failures, and empty states needed consistent handling across features.

03

Data visualisation

Restaurant and booking performance data needed to remain clear across responsive layouts and changing filters.

04

Team integration

Front-end delivery required coordination around backend work, endpoint changes, shared branches, and deadlines.

Outcome

What RestBoo demonstrates

Ownership of a substantial front end — from API integration and role-based workflows through responsive interfaces, analytics, and collaborative software delivery.

The project is my strongest example of working within a multi-developer team while taking responsibility for the complete user-facing implementation of an interconnected software product.
