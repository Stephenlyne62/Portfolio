Overview

The project

Emerald Eats required a modern website capable of presenting menus, catering services, merchandise, promotional media, and business contact information through a responsive experience.

The website also needed to be easy to update as the business evolved, allowing content, imagery, and branding to change without requiring a complete redesign.

Engineering

Technical approach

The website was built using semantic HTML, modern CSS, JavaScript, Bootstrap, Swiper, GLightbox, and AOS animations.

The focus was on creating a lightweight website that loaded quickly, worked consistently across devices, and remained straightforward to maintain as the client requested changes.

HTML CSS JavaScript Bootstrap Swiper GLightbox AOS Git

Changing requirements

The website evolved after launch with new branding, menu changes, content updates, and design revisions.

Responsive layouts

Performance

Media-heavy pages required optimisation to preserve loading speed.

Client communication

Requirements were gathered and translated into practical technical changes throughout the project.
