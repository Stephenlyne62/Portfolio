The Product

A simpler way
to choose a film.

Movie platforms often present users with large catalogues and broad genre categories, making the decision itself harder than it needs to be.

Movie Match approaches discovery differently. Users can begin with a mood, narrow results by decade, search directly for a title, and save films they want to revisit.

My Role

Designed and built independently.

I designed and implemented the complete front-end application, from the discovery experience and movie detail pages through shared state, persistence and responsive behaviour.

  • Mood and decade-based movie discovery
  • Live title search using TMDB data
  • Detailed movie, cast, crew and trailer views
  • Persistent personal watchlists
  • Client-side routing and shared application state
  • Responsive desktop, tablet and mobile layouts

Working with external data

TMDB provides separate datasets for search results, film details, credits, imagery and video content. Movie Match transforms those responses into consistent reusable interface components.

Defensive interface states

The application accounts for missing posters, unavailable trailers, incomplete production credits and empty search results so inconsistent API data does not break the user experience.

Challenges

Key engineering challenges

The main challenges came from coordinating filters, handling unpredictable external data and keeping application state consistent.

01

Combining filters

Mood, decade and search behaviours needed to work together without creating conflicting interface states.

02

API response handling

External data could contain missing images, incomplete credits, unavailable trailers or empty search results.

03

Persistent state

Watchlist changes needed to update immediately across the application and remain available after the browser was closed.

04

Responsive layouts

Large backdrops, posters, information panels and card grids needed to remain usable across a wide range of screen sizes.

Outcome

What Movie Match demonstrates

Independent delivery of a complete React application — from product design and third-party API integration through shared state, routing, persistence and responsive UI.

The project demonstrates my ability to turn complex external data into a usable front-end product, handle inconsistent API responses defensively, and take an application from initial interface design through to public deployment.
