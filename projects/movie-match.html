Overview

The product idea

Many movie platforms prioritise large catalogues and broad genre categories, which can make choosing a film feel more difficult rather than easier.

Movie Match was designed around a simpler discovery process. Users can begin with a mood, narrow results by decade, search directly for a title, and save films they want to revisit.

Ownership

What I built

I independently designed and implemented the complete front-end application.

  • Mood-based movie discovery using comedy, thriller, drama, and animation categories
  • Decade filtering covering films from the 1980s through the 2020s
  • Instant title search using live TMDB data
  • Detailed movie pages with cast, crew, production roles, and ratings
  • Trailer playback through an in-page modal
  • Persistent watchlist functionality using LocalStorage
  • Client-side routing and shared application state
  • Responsive layouts for desktop, tablet, and mobile screens

Engineering

Technical approach

Movie Match was built as a component-based React application. The interface retrieves movie, cast, crew, imagery, and trailer information from the TMDB API.

Shared state is managed through React Context, allowing watchlist information and application behaviour to remain consistent across pages and components.

LocalStorage provides lightweight persistence without requiring user accounts or a separate backend service.

Data

Working with external movie data

The TMDB API returns large and differently structured datasets for search results, film details, credits, imagery, and video content.

The application transforms that data into consistent UI components while accounting for missing posters, unavailable trailers, incomplete production credits, and empty results.

Challenges

Key engineering challenges

Combining filters

Mood, decade, and search behaviours needed to remain understandable without creating conflicting interface states.

API response handling

External data could contain missing images, incomplete credits, unavailable trailers, or empty search results.

Persistent state

Watchlist changes needed to update immediately throughout the application and remain available after the browser was closed.

Responsive movie layouts

Large backdrops, posters, information panels, and card grids needed to work across a wide range of screen sizes.

Deployment

Publishing the application

Movie Match is deployed through GitHub Pages and is publicly accessible as a complete front-end application.

The project demonstrates how a client-side React application can combine third-party API data, browser storage, routing, and responsive UI without requiring a custom backend.
