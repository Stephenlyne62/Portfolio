Overview

Why I built it

World Cup prediction competitions are often managed through spreadsheets, messages, and manual score calculations. As tournaments progress, this becomes difficult to maintain and makes it harder for participants to follow the standings.

I built a dedicated web application to automate the prediction process, centralise tournament data, and provide a better experience for both participants and organisers.

Ownership

What I built

I independently designed, developed, tested, and deployed the complete application.

  • Authentication and participant account handling
  • Fixture management for all 104 tournament matches
  • Score prediction creation and editing
  • Automatic prediction locking at fixture kick-off
  • Match scoring and live leaderboard calculation
  • Tournament outright predictions and wildcard categories
  • Responsive desktop and mobile interfaces
  • Deployment and database integration using Vercel and Supabase

Engineering

Technical approach

The application was built with Next.js and TypeScript, with Supabase providing authentication and PostgreSQL-backed data storage.

Reusable components handle fixtures, predictions, leaderboards, navigation, and tournament outrights, while server-side logic manages scoring and competition rules.

Prediction availability is determined using each fixture's kick-off time, preventing updates once a match has begun.

Business Logic

Prediction scoring

Predictions are scored using a simple rule set designed to reward exact predictions while still recognising the correct match outcome.

3 points Correct score
1 point Correct result
5 points Correct outright

Challenges

Key engineering challenges

Prediction locking

Users needed to retain editing access before kick-off while being prevented from changing predictions once a fixture had started.

Automated scoring

Match results needed to be compared against saved predictions consistently and reflected accurately in the leaderboard.

Tournament scale

Supporting 104 fixtures required reusable components, structured data, and manageable filtering across a long tournament schedule.

Responsive data display

Fixtures, standings, and prediction controls needed to remain clear and usable on smaller screens.

Deployment

Shipping the application

The application is deployed through Vercel, with Supabase providing authentication and PostgreSQL data storage.

Participants can access the application online, manage their predictions before kick-off, and follow the leaderboard without relying on spreadsheet updates or manual score messages.
