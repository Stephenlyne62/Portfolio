Educational Software Synthesizer

2026 MSc Thesis Individual Project C++ & DSP

My contribution

Research, software architecture, C++ development, DSP implementation, interface design, usability testing, and evaluation.

A C++ audio application investigating whether a goal-oriented synthesizer interface can make sound design more accessible to novice users without reducing functionality.

Engineering decision

Used one shared DSP engine across both interface variants so usability differences could be attributed to interface design rather than differences in audio generation.

  • Developed two functionally equivalent synthesizer interfaces
  • Built a shared object-oriented C++ and DSP engine
  • Applied HCI principles to an educational software product
  • Designed controlled testing with novice users
